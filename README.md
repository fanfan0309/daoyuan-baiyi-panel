# 《道渊》百艺修习面板

《道渊》工坊 DLC 的 Tavern Helper 远程面板脚本仓库。此仓库只托管面板脚本和远程导入入口；世界书、角色局部正则及整合包仍由 DLC 作者单独提供，不会由远程脚本自动导入。

## 当前版本

当前面板脚本为 **v0.3.8**。炼丹控火与炼器塑形均可选择本次火源，从储物袋读取明确记载的火源，也可补充现场地火、异火或借用来源；选项会随工序保留并写入行动草稿。材料列表的上限检查覆盖炼丹药材、炼器材料和器灵专用材料：器灵候选原有的 12 条展示与 8 项选择限制已取消，炼丹和炼器材料候选按可读储物袋内容完整展示，不按固定条数截断。炼丹与炼器操作还包含药材辨识、药材图鉴、器物材料辨识、器物图鉴、独立器灵页及玉佩专属工序。场景操作结果会整理成输入栏草稿，玩家检查后自行发送。面板按钮打开悬浮窗，不创建新的聊天楼层，也不会自动发送消息。打开场景时需要网络访问 jsDelivr 图片资源。

本仓库不包含世界书与正则。本版配套世界书和正则要从 DLC 独立导入包获取；只更新面板脚本时，无需重复导入它们。图片资源随本仓库的版本标签托管；请使用固定版本链接，不要删除当前版本的 `assets/panel/` 文件。

## Tavern Helper 远程导入

在 Tavern Helper 脚本管理中导入仓库里的 `TavernHelper-远程导入.json`。入口固定读取本仓库的 v0.3.8 `index.js`：

`https://cdn.jsdelivr.net/gh/fanfan0309/daoyuan-baiyi-panel@v0.3.8/index.js`

也可以在酒馆助手脚本中使用：

```js
import('https://cdn.jsdelivr.net/gh/fanfan0309/daoyuan-baiyi-panel@v0.3.8/index.js')
  .catch(error => console.error('[道渊百艺] 远程面板加载失败：', error));
```

远程导入 JSON 已包含「百艺面板」按钮。如果手动粘贴代码，需要自行添加同名脚本按钮。保留一份启用的百艺脚本，避免本地版和远程版重复打开。

## 导入次序

1. 将 DLC 随附的世界书文件导入《道渊工坊》草稿。
2. 选择“追加”，逐个导入 DLC 随附的四个正则文件。
3. 在 Tavern Helper 脚本库导入仓库里的 `TavernHelper-远程导入.json`，由它加载本版 `index.js`；也可以手动导入 DLC 随附的面板脚本 JSON。
4. 按 DLC 导入说明核对工坊预览。识别失败或条目数为 0 时取消导入。
